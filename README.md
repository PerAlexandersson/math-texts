# Math texts

This repository will contain mathematical notes and course texts published at
`math.qxy.se`.

The site is intended as a collection of independently organized texts sharing
one publishing system, visual language, bibliography infrastructure, and
search interface. Planned collections include:

- `/colored-matroids/` for the evolving theory of colored matroids and its
  Lean formalization;
- `/courses/` for lecture notes, exercises, and related course material;
- `/notes/` for smaller expository texts.

This is the initial repository setup. No website has been deployed yet, and
the source format and build system have not been selected.
